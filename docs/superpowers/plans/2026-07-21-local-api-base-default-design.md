# 本地前端 API 地址自动配置设计

## 背景

前端默认使用同源 API 地址。开发时页面与 Spring Boot 后端通常运行在不同端口，页面会把
`/api/v1/auth/guest` 发往前端静态服务器，导致游客登录返回 404。后端本地默认监听
`http://localhost:8090`。

## 目标

- 页面运行在 `localhost` 或 `127.0.0.1` 时，若没有显式配置，默认使用同一主机的 `8090` 端口。
- 非本地环境继续使用同源 API，以兼容 Nginx `/api/` 反向代理。
- URL 参数 `apiBase` 优先于已保存配置，已保存配置优先于自动默认值。
- 不改变认证、游客创建或其他 API 路径。

## 设计

扩展前端运行时配置解析：在 URL 参数和本地存储都没有有效 `apiBase` 时，根据页面
`origin` 判断是否为本地开发环境。`localhost` 和 `127.0.0.1` 返回
`http://<当前主机>:8090`，其他主机返回空字符串以继续使用同源请求。

`apiBase` 的优先级为：

1. URL 查询参数中的有效 `apiBase`
2. localStorage 中保存的有效 `apiBase`
3. 本地开发环境自动地址
4. 空字符串（生产同源）

## 错误处理与兼容性

现有 URL 校验规则保持不变。自动默认值不写入 localStorage，避免临时开发默认值覆盖用户
显式配置。IPv6 本地地址本次不纳入范围，避免扩大行为面。

## 测试

- 新增 `localhost` 页面默认得到 `http://localhost:8090` 的单元测试。
- 新增 `127.0.0.1` 页面默认得到 `http://127.0.0.1:8090` 的单元测试。
- 保留并验证生产域名默认同源。
- 保留并验证 URL 参数、存储配置的优先级。
