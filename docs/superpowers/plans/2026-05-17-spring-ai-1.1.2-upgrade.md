> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**目标:** 升级 Spring AI 从 1.1.0 到 1.1.2，兼容 spring-ai-alibaba mem0 模块

**背景:** spring-ai-alibaba 官方目前只发布了支持 Spring AI 1.1.2 的版本（1.1.2.3），1.1.6+ 版本暂不支持 mem0。1.1.2 是能兼容 mem0 的最新正式版本。

---

## 1. 升级内容概览

| 序号 | 依赖/组件 | 当前版本 | 目标版本 | 类型 |
|-----|----------|---------|---------|------|
| 1 | spring-ai-bom | 1.1.0 | 1.1.2 | 升级 |
| 2 | spring-ai-alibaba-starter-memory-mem0 | 1.1.0.0-M4 | 1.1.2.3 | 升级 |

---

## 2. 破坏性变更兼容

Spring AI 1.1.2 引入了以下破坏性变更需要适配：

### 2.1 PromptChatMemoryAdvisor 废弃

| 变更 | 说明 |
|-----|------|
| 类名 | `PromptChatMemoryAdvisor` → `MessageChatMemoryAdvisor` |
| 必需参数 | 必须显式传入 `conversationId`，不再支持隐式会话 ID |
| 引入版本 | 1.1.0 开始废弃，1.1.6 完全移除 |

**影响文件:**

| 文件路径 | 改动点 |
|---------|-------|
| `ai-agent-study-domain/.../AiClientAdvisorTypeEnumVO.java` | 第 39 行 |
| `ai-agent-study-trading/.../IntentRoutingNode.java` | 第 68 行 |
| `ai-agent-study-app/.../AiAgentTest.java` | 第 86, 217, 257 行 |

@Test
public void testConversationIsolation() {
    String conversationId1 = "session-001";
    String conversationId2 = "session-002";

    // 会话1：用户A说"我喜欢苹果"
    ChatClient chatClient1 = createChatClient(conversationId1);
    chatClient1.prompt().user("我喜欢苹果").advisors(a -> a
        .param(CHAT_MEMORY_CONVERSATION_ID_KEY, conversationId1)
    ).call();

    // 会话2：用户B说"我喜欢香蕉"
    ChatClient chatClient2 = createChatClient(conversationId2);
    chatClient2.prompt().user("我喜欢香蕉").advisors(a -> a
        .param(CHAT_MEMORY_CONVERSATION_ID_KEY, conversationId2)
    ).call();

    // 验证会话1不知道会话2的内容
    String response1 = chatClient1.prompt().user("我喜欢什么？").advisors(a -> a
        .param(CHAT_MEMORY_CONVERSATION_ID_KEY, conversationId1)
    ).call().content();

    assertTrue("会话1应记得喜欢苹果", response1.contains("苹果"));
    assertFalse("会话1不应知道会话2的内容", response1.contains("香蕉"));
}
