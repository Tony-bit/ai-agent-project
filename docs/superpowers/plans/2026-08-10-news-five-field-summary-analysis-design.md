# 新闻五字段摘要级分析设计

## 背景

当前新闻检索通过东方财富搜索接口一次性取得新闻列表。每条新闻已经包含标题、摘要、来源、发布时间和链接，但现有分析链路并未完整利用这些字段：固定关键词评分只读取标题和摘要，LLM 输入包含标题、摘要、来源和发布时间，却遗漏了链接。

本设计参考 TradingAgents 原版的摘要级新闻分析方式：不访问文章详情页，不读取完整正文，直接基于搜索接口返回的结构化新闻信息进行分析。

## 目标

1. 将 `title`、`summary`、`source`、`publishTime`、`url` 五个原始字段完整传递给新闻分析 LLM。
2. 保留 `sentimentScore` 作为唯一的单篇新闻观点字段，表示文章对目标股票的正面或负面倾向。
3. 让 LLM 在报告级别综合来源、时效、摘要完整性和链接信息，输出 `confidence` 与 `dataQuality`。
4. 明确结论属于摘要级分析，不得声称已经读取或核验文章正文。
5. 不增加文章详情页请求，保持现有新闻检索耗时和外部请求数量。
6. 只让最近 15 天内的新闻参与当前分析，避免历史新闻影响当前立场判断。

## 非目标

1. 不抓取新闻正文。
2. 不访问或探测每篇新闻的 `url`。
3. 不新增 `metadataQualityScore`、`validityScore` 或单篇 `sentimentConfidence`。
4. 不根据来源、发布时间或链接修改文章的正负倾向。
5. 不把摘要级判断表述为事实真实性核验。

## 字段职责

| 字段 | 来源 | 分析职责 |
|---|---|---|
| `title` | 搜索结果标题 | 参与关键词评分和 LLM 语义分析 |
| `summary` | 搜索结果内容摘录 | 参与关键词评分和 LLM 语义分析 |
| `source` | 搜索结果 `mediaName` | 供 LLM 判断来源是否明确、来源是否单一 |
| `publishTime` | 搜索结果 `date` | 供 LLM 判断新闻时效性 |
| `url` | 根据搜索结果 `code` 生成 | 作为可追溯出处传递，不访问、不视为正文已核验 |
| `sentimentScore` | 固定关键词评分器或数据源原生评分 | 唯一的单篇观点数值，范围为 `-1` 到 `1` |

`source`、`publishTime` 和 `url` 只影响报告级 `confidence` 与 `dataQuality`，不进入 `sentimentScore` 计算。

## 数据流

```text
东方财富新闻搜索（一次请求）
    -> NewsItemVO 五个原始字段
    -> 15 天新闻时间窗口过滤
       -> 过期或明显未来的新闻从本次分析排除
       -> 时间缺失或无法解析的新闻保留并标记质量风险
    -> NewsItemSentimentEnricher
       -> 使用 title + summary 补充 sentimentScore
    -> NewsAnalysisStructuredProcessor
       -> 清洗、精确去重、构建包含五字段和 sentimentScore 的 JSON
    -> 新闻分析师 LLM
       -> 事件级语义归并
       -> 新闻立场与影响分析
       -> 报告级 confidence / dataQuality
    -> NewsReportVO
```

整个流程不得对 `url` 发起后续 HTTP 请求。

## 新闻时间窗口

1. 个股新闻分析窗口固定为最近 15 天。
2. 过滤基准使用当前分析时间，时区为 `Asia/Shanghai`。
3. 发布时间早于“当前分析时间减 15 天”的新闻，从本次分析列表中排除。
4. 发布时间恰好位于 15 天边界的新闻保留。
5. 发布时间明显晚于当前分析时间的新闻视为异常数据，从本次分析列表中排除。为容忍接口时间精度和本机时钟偏差，允许不超过 10 分钟的未来时间。
6. 发布时间为空或无法解析时保留新闻，不因单条时间格式异常丢失其余可用字段；LLM 必须在 `dataQuality` 中说明时效无法确认。
7. 过滤只作用于当前内存中的分析列表，不删除 provider 返回的原始数据，也不删除任何持久化数据。
8. 被过滤的新闻不进入关键词评分器、不传给 LLM，也不参与最终新闻评分。

## 固定评分规则

现有 `news-keyword-score-v1` 保持不变：

1. 标题按完整权重参与评分。
2. 摘要按 `0.6` 权重参与评分。
3. 来源、发布时间和链接不参与评分。
4. 没有匹配到有效关键词时保持评分不可用，不用中性分伪装未知状态。
5. 数据源已经提供 `sentimentScore` 时保留原值，只为空值补评分。

## LLM 输入与提示词

`NewsAnalysisStructuredProcessor` 为每条保留新闻输出：

```json
{
  "id": 1,
  "originalId": 1,
  "publishTime": "2026-08-04 15:48:00",
  "source": "财中社",
  "title": "公司股东解除部分质押",
  "summary": "公司发布公告，股东解除部分质押并办理新增质押。",
  "url": "https://finance.eastmoney.com/a/example.html",
  "sentimentScore": -0.1
}
```

提示词必须明确：

1. 使用标题和摘要判断文章观点与事件影响。
2. 使用来源、发布时间和链接评估整体数据质量和分析置信度。
3. 链接缺失不等于新闻无效，但应作为可追溯性不足写入 `dataQuality`。
4. 来源为空、摘要过短、时间无法解析、新闻明显陈旧或标题与摘要方向冲突时，应降低 `confidence` 并在 `dataQuality` 中说明。
5. 多篇媒体报道同一事件时继续进行事件级语义归并，不重复加权。
6. 只有标题和摘要时，证据层级保持 `summary`，不得假设已经读取正文。
7. `url` 仅用于出处说明，不要求模型访问链接，也不得将链接存在解释为事实已经核验。

## 缺失字段与降级

1. 标题为空且摘要为空时，关键词评分保持不可用；LLM 应将该条视为证据不足。
2. 摘要为空但标题可用时，允许基于标题判断观点，但报告应降低置信度。
3. 来源为空时仍保留新闻，报告应说明来源信息不足。
4. 发布时间为空或无法解析时仍保留新闻，报告应说明无法确认时效；能够解析且超过 15 天的新闻已经在进入 LLM 前排除。
5. 链接为空或格式异常时仍保留新闻，不进行网络探测，报告应说明可追溯性不足。
6. 单条字段缺失不得导致整个新闻节点失败。

## 代码变更范围

1. 修改 `NewsAnalysisStructuredProcessor`，在准备、去重后的 LLM 新闻条目中保留并输出 `url`。
2. 修改 `NewsAnalysisStructuredProcessor` 生成的 `instructions`，明确五字段职责和摘要级证据边界；该字段通过现有 `stockData` 占位符进入所有 Prompt 模式。
3. 在新闻进入 `NewsItemSentimentEnricher` 前增加可独立测试的 15 天时间窗口过滤，统一使用 `Asia/Shanghai` 分析时间。
4. 不修改已归档的旧 Prompt 模板或历史数据库迁移，避免破坏 Prompt 版本快照的一致性。
5. 不修改 `NewsKeywordSentimentScorer` 的权重和关键词规则。
6. 不修改新闻 provider 的请求方式，不新增外部接口调用。

## 测试策略

1. 验证五个原始字段和 `sentimentScore` 全部进入 LLM 输入。
2. 验证 HTML 高亮标签被清理后，URL 原值仍被保留。
3. 验证 URL 缺失时字段省略或为空，但新闻条目仍然保留。
4. 验证精确重复新闻去重后，保留条目的 URL 与原始编号关系正确。
5. 验证 Prompt 明确包含“不访问链接”“摘要级证据”“来源、时间、链接只影响报告质量”等约束。
6. 回归关键词评分器，确认来源、时间和链接不会改变 `sentimentScore`。
7. 回归新闻分析节点，确认不产生文章详情页 HTTP 请求。
8. 验证 15 天内和恰好位于 15 天边界的新闻被保留，超过 15 天的新闻被排除。
9. 验证超过当前分析时间 10 分钟的未来新闻被排除，10 分钟容差内的新闻被保留。
10. 验证发布时间为空或无法解析的新闻被保留，并在 LLM 输入说明中要求报告时效风险。
11. 验证被时间窗口排除的新闻不参与关键词评分、不进入 LLM 输入。

## 验收标准

1. 每条可用新闻的五个原始字段均可传递到 LLM；缺失字段按降级规则处理。
2. `sentimentScore` 仍是唯一的单篇新闻观点字段。
3. 报告级 `confidence` 和 `dataQuality` 能说明来源单一、摘要不足、时间异常或链接缺失等问题。
4. 输出不得声称已读取新闻正文或完成事实真实性核验。
5. 新闻分析的外部请求数量与当前版本一致，不因文章数量增加详情页请求。
6. 只有最近 15 天内、位于未来时间容差内，或发布时间无法确认的新闻能够进入分析；确认超过时间窗口的新闻不得影响最终结果。
