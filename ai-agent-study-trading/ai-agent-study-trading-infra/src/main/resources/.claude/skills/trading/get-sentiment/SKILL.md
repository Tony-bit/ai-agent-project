# 获取市场情绪

## 工具信息
- **Skill Name**: `get-sentiment`
- **Tool Name**: `get_sentiment`

## 功能说明
返回股票的情绪评分、看涨看跌比例和不同周期情绪趋势，用于识别市场态度和短期风险偏好。

## 输入参数
| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| ticker | string | 是 | 6 位股票代码 | "300750" |

## 返回格式
Markdown 文本，包含综合情绪评分、评级、短中长期情绪和恐惧贪婪指数。

## 使用场景
1. 情绪面分析师判断市场是否拥挤。
2. 用户想看短期市场情绪是否支持交易决策。

## 注意事项
- 情绪指标变化快，应结合新闻和价格走势解释。
- 不应单独作为买卖结论依据。
