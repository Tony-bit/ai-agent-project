# 根据名称搜索股票

## 工具信息
- **Skill Name**: `search-stock-by-name`
- **Tool Name**: `search_stock_by_name`
- **Implementation**: ToolCallback (`TradingToolCallbacks`)

## 功能说明
当用户没有提供股票代码，只提供公司名、简称或自然语言提及时，先通过该工具解析候选股票代码。唯一匹配时，将返回的股票代码作为后续行情、基本面、技术面、新闻或情绪工具的 `ticker`。

## 输入参数
| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| name | string | 是 | 股票中文名称，支持模糊匹配 | "贵州茅台" |

## 返回格式
Markdown 列表文本，返回候选股票名称、代码、交易所和市场信息。后续工具使用返回结果中的 6 位股票代码作为 `ticker`。

## 使用场景
1. 用户说“分析一下贵州茅台”但没有给代码。
2. 需要确认公司简称对应哪只 A 股股票。

## 注意事项
- 当用户只给公司名称时，应优先调用该工具。
- 若返回多个候选，应让后续流程做澄清或消歧。
