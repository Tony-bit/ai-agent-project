# 获取股票新闻

## 工具信息
- **Skill Name**: `get-stock-news`
- **Tool Name**: `get_stock_news`

## 功能说明
返回指定股票的近期新闻，帮助模型识别催化剂、负面舆情和短期事件风险。

## 输入参数
| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| ticker | string | 是 | 6 位股票代码 | "000001" |
| limit | integer | 是 | 返回条数上限 | 5 |

## 返回格式
Markdown 列表文本，包含新闻标题、来源、发布时间、摘要和情感得分。

## 使用场景
1. 新闻分析师梳理近期消息面。
2. 用户询问近期是否有利好、利空或突发事件。

## 注意事项
- 新闻时效性强，优先关注最近发布时间。
- 数量过多时应控制 `limit`，避免无关噪音。
